# ZeroMadLife Blog

个人技术博客，记录 SAGE、AI Agent 工程、后端系统与持续成长。

- Production: <https://blog.sagecompanion.top>
- SAGE: <https://sagecompanion.top>
- GitHub: <https://github.com/ZeroMadLife>

## Development

```bash
npm install
npm run dev
npm run build
```

站点由 Astro 静态生成，通过 GitHub Actions 部署到 GitHub Pages。公开文章必须在 frontmatter 中同时设置：

```yaml
visibility: public
publish: true
```

原始面试记录和私有知识不进入本仓库。
