## 我怎样理解知识

知识不是收集来的文件数量，也不是一次回答生成的漂亮结论。对我来说，它至少要经过四步：

1. 从真实问题出发，保留来源和上下文；
2. 通过代码、实验或对比研究形成判断；
3. 记录证据、失败条件和仍然不知道的部分；
4. 回到下一次实践中，验证它能不能继续工作。

我更在意知识能不能回到下一次实践里继续工作：能复现、能解释，也能在条件变化时知道它为什么失效。

## 接下来学习什么

### 系统基本盘

继续打磨 Java、操作系统、网络、数据库、缓存、消息系统、分布式一致性、性能分析和可观测性。这些决定了系统遇到真实流量和真实故障时能否站住。

### Agent 工程

深入 Context Engineering、Memory、Tool Use、MCP、Harness、Graph、Multi-Agent、Human-in-the-loop 与 Eval，重点理解能力之间的边界、状态流转和恢复机制。

### 知识与检索

学习文档解析、分块、Embedding、混合检索、Rerank、GraphRAG、citation、revision 和权限隔离，用可复现实验决定技术取舍。

### 交付与安全

补齐 Docker、CI/CD、Kubernetes、Sandbox、资源限制、密钥与供应链安全，让 Agent 不只在演示环境里工作。
